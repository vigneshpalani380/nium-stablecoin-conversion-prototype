# 08 — Build and Agent Guide

Execute tasks in dependency order, one active implementation task at a time. Read master PRD, relevant specs, AGENT_MATRIX and assigned task before coding.

Rules: stay within allowed files; no silent scope expansion; no unnecessary dependencies; Decimal for money; domain rules out of controllers; tests with every financial rule; no live funds, credentials or paid integrations; report changed files, tests and deviations.

Stop for product-owner approval before changing fee calculation/denomination, supported pairs, balance semantics, adding a separate ledger table, live integration, quote validity or idempotency semantics.

Task completion report: objective, changed files, acceptance criteria, tests/commands/results, deviations, unresolved risks and next task.
