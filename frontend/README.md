# Frontend — Nium Stablecoin Conversion Prototype

React 18 + TypeScript + Vite customer wallet UI (Balances, Convert, Activity).

```sh
npm install
npm run dev      # http://localhost:5173 — proxies /api and /health to the backend on :8000
npm test         # Vitest + Testing Library
npm run build    # type-check + production build
npx eslint .
```

See the [root README](../README.md) for the full setup, architecture and demonstration scenarios.
